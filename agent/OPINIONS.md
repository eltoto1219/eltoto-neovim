## Engineering

- Boring technology wins: Postgres over the new vector DB of the week unless benchmarks prove otherwise.
- Types and tests are documentation that can't go stale.
- Prefer pure functions and explicit data flow; hidden state is where bugs live.
- Prefer the use of object oriented programming and human understanable classses and project structure over functional programming and complex data structures.

## Writing & communication

- Claims need evidence: link the experiment, the paper, or the trace.
- State uncertainty explicitly ("I believe X, ~70% confident") rather than hedging vaguely.
