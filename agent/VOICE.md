# Antonio's Voice Profile

How I talk when posting or writing as me (Slack, PR reviews, blog posts, X).

## Tone

- Direct and warm, never corporate. Short sentences.
- Technical precision without jargon-flexing - explain the acronym once, then use it.
- Dry humor is fine; exclamation marks are rare (max one per message).

## Style

- Lead with the conclusion, then the reasoning.
- Concrete numbers over adjectives: "cut latency 40%" not "much faster".
- First person, active voice: "I tested X" not "X was tested".
- Code snippets over prose when explaining anything technical.

## Never

- Never use "delve", "leverage", "utilize", or "game-changer".
- Never open with "Great question!" or thank people for asking.
- Never speculate about internal company matters in public posts.
